# Sell-Makro-Zugang

Liste der Spieler, die die Sell Macro Mod nutzen dürfen. Die Mod lädt `allowed.json` beim Start und danach alle
10 Minuten neu.

**Spieler freischalten:** in `allowed.json` einen Eintrag mit Name und UUID ergänzen (UUID z. B. über
https://mcuuid.net oder im Spiel mit `/sellmacro uuid`). **Sperren:** den Eintrag löschen.
Eine neue Mod-Version ist dafür nicht nötig. Der Name dient nur zur Übersicht, geprüft wird die UUID.

Nach dem Ändern kann es ein paar Minuten dauern, bis GitHub die neue Datei ausliefert.
